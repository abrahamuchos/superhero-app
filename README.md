# SuperHero App
An app for viewing information about superheroes. It is made solely for educational purposes.

<img src="/docs/screenshots/super-hero-app.png" width="200px" alt="super-hero-app">

It is made solely for educational purposes.

## ✅ Features

- Show Info about SuperHeros
- Search by name


## ⚙️ Tech Stack

- Flutter 3.6.0


## 💾 Installation

Install and run

1. Clone and move to folder
```bash
$ git clone git@github.com:abrahamuchos/superhero-app.git
$ cd superhero-app
```

2. Install dependencies
```bash
$  flutter pub get
```

3. Run dev `flutter run`

If you encounter issues, run `flutter doctor` to check for missing dependencies or configuration errors.
